# 🐍 Atividades com Python e Flet

Projeto desenvolvido durante as aulas de Desenvolvimento de Sistemas, utilizando **Python** e a biblioteca **Flet** para criação de interfaces gráficas.

## 📱 Sobre o projeto

O projeto reúne algumas atividades práticas desenvolvidas com Flet, explorando a criação de interfaces, textos, campos de formulário, botões, cores e componentes visuais.

### 🎨 Atividade 1 — Gugu do Grau

Uma interface simples com título e subtítulo, utilizando diferentes tamanhos e cores de texto.

- Título: **Bertaco**
- Subtítulo: **Rei do capa**
- Fundo na cor verde
- Textos personalizados

### 📝 Atividade 2 — Formulário

Uma tela de formulário desenvolvida com componentes do Flet.

Possui:

- Título **Formulário**
- Campo para digitar o nome
- Checkbox para aceitar os termos de uso
- Botão **Enviar**
- Personalização de cores, tamanhos e bordas

### 👤 Atividade 3 — Perfil

Uma tela de apresentação contendo informações do usuário.

Exibe:

- Nome
- Curso
- E-mail
- Telefone
- Ícones para representar as informações
- Cartão com bordas arredondadas

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 🎨 Flet

## 🎯 Objetivo

Praticar a criação de **interfaces gráficas com Python**, utilizando os componentes e recursos disponibilizados pelo Flet.

## 📚 Aprendizados

Durante a atividade foram praticados conceitos como:

- Criação de páginas com Flet
- Textos e estilos
- Cores e tamanhos
- Campos de entrada
- Botões
- Checkbox
- Ícones
- Containers
- Alinhamento de elementos
- Bordas arredondadas
- Organização de interfaces
